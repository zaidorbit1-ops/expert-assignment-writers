# Expert Assignment Writers UK - React Website

A beautiful, modern, and fully responsive React website for Expert Assignment Writers UK. Built with React, Tailwind CSS, and Framer Motion for smooth animations.

## Features

✨ **Modern Design**
- Beautiful light theme with custom colors (#0d3055 primary, #cfa049 secondary)
- Responsive layout that works on all devices
- Smooth animations and hover effects

🎯 **Sections Included**
- Fixed Header with navigation and mobile menu
- Hero section with quote form
- Trust bar with university logos
- Services showcase
- Why Us section (Bento layout)
- 4-Step Process
- Testimonials carousel
- FAQ accordion
- Final CTA section
- Full footer

🚀 **Performance**
- Optimized animations with Framer Motion
- Smooth scrolling
- Lazy loading ready
- Mobile-first responsive design

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Technologies Used

- **React 19.2** - UI library
- **Tailwind CSS 3.4** - Utility-first CSS framework
- **Lucide React 0.294** - Beautiful icon library
- **Framer Motion 10.16** - Animation library
- **PostCSS 8.4** - CSS processing
- **Autoprefixer 10.4** - Browser prefix auto-adding

## Customization

### Change Colors
Update the color values in `tailwind.config.js`:
```js
colors: {
  primary: {
    900: '#0d3055',  // Change primary color
  },
  secondary: {
    700: '#cfa049',  // Change secondary color
  },
}
```

### Update Content
Edit the content in each component file (text, testimonials, FAQs, etc.)

### Add Images
Place images in the `public` folder and reference them in components:
```jsx
<img src="/your-image.png" alt="description" />
```
